## ✨ Features

- ➕ **Add New Task** – Create tasks with a title and description.
- 👁️ **View All Tasks** – Display all tasks with their current status.
- ✅ **Mark Task as Complete** – Update task status to completed.
- 🗑️ **Delete Task** – Remove unwanted tasks from the list.
- 🚪 **Exit Gracefully** – Safely close the application.
- 🎨 **Clean Console UI** – Uses emojis and box-drawing characters for better readability.
- 🧱 **Object-Oriented Design** – Built using `Task` class and `ArrayList` for dynamic storage.
